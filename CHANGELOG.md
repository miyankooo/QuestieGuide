# Questie Guide

## Unreleased

- One Filter button next to the search box replaces the settings column, so the quest list uses the full window width. It holds availability, quest types, Show Completed, the level range and the sort order, and its reset button shows when any filter is changed.
- Rows follow Forever's quest log: `[12+]` for elite quests and one tag such as `(Dungeon)` or `(Elite)` after the name. The Elite (Group) filter is now Elite.
- Rows show a status only for In Questlog, Requires Level N and Missing Pre-Quest.
- Zones start collapsed, except the zone you are in and the Next zone.
- Clicking a quest in combat sets the waypoint and explains why the map stays closed, instead of Blizzard's "Interface action failed" error.
- Item tooltips no longer error inside dungeons when Forever hides the item data.
- Tags missing on the first open fill in a moment later.
- A Missing Pre-Quest row no longer lists a quest that can never unlock.
- Row colours match Questie's own quest titles.
- Clicking a Questie map pin opens the guide only for available quests. Objective and turn-in pins behave as in Questie.
- Link in Chat sends the native quest link for quests in your log.
- Entering a dungeon names how many of its quests you could still pick up.
- The minimap and addon menu tooltip shows how many quests you can pick up in your zone, and the Next zone with its XP.
- `/qg minimap` shows or hides the minimap button.
- The level-up message appears in chat only, and there is no intro line at login.
- Current Zone says so when your zone has no Questie data.
